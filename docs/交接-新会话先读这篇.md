## 4. 已经拿到的硬证据（面试直接讲，别改数字）

**闭环实测（吹风机物理加热真传感器）**：

```
16:32:55  31.40℃  FALSE        ← 低于阈值 32
16:32:56  34.20℃  TRUE         ← 越过 32，PLC 判定报警
16:33:10  41.40℃  TRUE         ← 峰值
16:38:28  31.50℃  FALSE        ← 自然冷却，自动解除
```
升幅 10.0℃；49 个样本中 48 个与独立判定一致；**Java 全程没有做判断**（判断在 PLC 侧）。

**真传感器参数**：艾克姆 **IKM10000WS01**（固件 V025002）· 供电 5~30V（实测 5V）· 端子 ①VIN ②GND ③A ④B · **COM7** · 9600-8-N-1 · 从站 1 · **FC03** · 单轮 29~43ms（首轮 128ms）· 30 点 100% GOOD。

**USB-485 板**：FT232R（`VID_0403&PID_6001`，序列号 AI3N11CH），FTDI VCP 2.12.36.20，5 个端子 `T/R+ T/R- RXD+ RXD- GND`，**无 VCC**（不能给传感器供电），`RXD±` 空着。

**字节序实测**：CODESYS REAL = **CDAB**；RTU 测试桩 = **ABCD**。
⚠️ 判字节序**必须用低 16 位非零的值**（`90.0`/`25.5` 验不出来，要用 `90.1`/`25.6`）。

## 5. 七条可以直接背的结论（面试用）

1. **PLC 管「现在」，Java 管「过去和远方」** —— PLC 10ms 扫描、闭环、联锁、**断网也生效**、不存历史；Java 秒级采集、时序库、告警去抖、报表。
2. **「电商里 Java 是老板，工业里 Java 是记录员。」**
3. **软 PLC ≠ 仿真器**：CODESYS Control Win 是**真实运行时**；PLCSIM / GX Simulator 才是仿真器。
4. **Modbus 无语义，OPC UA 有信息模型** —— 「快递柜编号」vs「带标签的快递」。
5. **ISA-95 分层**：L0 现场 → L1 PLC → L2 SCADA/HMI → L3 MES → L4 ERP；EAM/CMMS 管设备维修。
6. **16 位整数 + 缩放**是真实国产仪表的主流形态（读到 253 → 25.3℃，scale=0.1）；4 字节 float 反而要赌字节序。
7. **AI 合规三层**：公有云 API（军工**禁止**）/ 私有化部署（主流）/ 涉密网物理隔离（**零 AI**）。→ 讲 AI 经验时必须强调「**数据不出域**」。

## 7. 已经踩过的坑（别重来）

| 坑 | 真因 | 教训 |
|---|---|---|
| 白扫 16 组串口参数全无回应 | **A/B 两根线根本没接**（只接了电源） | 排障顺序必须是 **物理 → 电平 → 参数 → 数据** |
| 传感器通电灯不亮 | **没共地**（GND 只接了电源负，没接 USB-485 的 GND） | 补 GND 后灯才亮（实测事实） |
| 温湿度读反了 | 假设 `offset0=温度`，实测 **`offset0=湿度`** | 靠读原始值反推，别靠猜 |
| FC04 返回异常码 `01` | 该设备**只支持 FC03** | 异常码 01 = 非法功能，02 = 非法数据地址 |
| TIA Portal 装不上 | Win11 **Home China**（`CoreCountrySpecific`），官方只支持 Pro/Enterprise；且可用内存仅 1.7~1.9 GB | 转三菱（这条建议曾违背已有结论，记为 AI 判断失误） |
| 罗克韦尔 CCW 下不了 | `Location` 必须是 Rockwell 已存在客户站点 | 个人下不了，审核 24~48h → 放弃 |
| PowerShell `[IO.File]` 走进程 CWD | CWD 是 `D:\java\csmall` | 一律用**绝对路径** |
| PowerShell 直调 java 拆坏 `-Dstdout.encoding=UTF-8` | 参数被拆 | 用 `.cmd` 包装 |
| cmd 把 wsl 参数里的 `>` 当重定向 | — | 别用 cmd 包 wsl |
| `write()` 不校验应答 | 1503 没监听也报"写成功" | 写操作必须读回确认 |
| `Out-File -NoNewline` 把 `.sh` 压成一行 | — | bash 解析不报错但脚本失效 |
| GX Works2 元件"挪不动" | 梯形图不是画布，元件不能拖 | 改顺序 = 删了按顺序重输 |
| GX Works2 输入总跑到最右边 | **无触点指令**（CMP/MOV）不能裸挂母线，被推到行末压右母线 | 前面挂 `LD M8000`（常 ON） |
