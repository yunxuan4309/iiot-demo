## 二、16 个坑（每条一句话）

| # | 坑 | 一句话 |
|---|---|---|
| 1 | 字序错 | 不报错，变成天文数字或 0 |
| 2 | 40001 当 offset | **永远超时**，不是读错值 |
| 3 | 断线补 0 | 把故障伪装成正常 |
| 4 | 单设备卡死 | 线程/连接/时间三重隔离 + 退避 |
| 5 | TDengine 只听 IPv6 | 要 `-Djava.net.preferIPv6Addresses=true` + `localhost` |
| 6 | WSL2 免 root | TDengine 在 WSL 里跑，Windows 装不了服务端 |
| 7 | UTC/Z 时区 | 不转就整图偏 8 小时 |
| 8 | 装了 Wireshark 抓不了 | 没装 Npcap |
| 9 | Npcap 不勾 loopback | 抓不到 127.0.0.1 |
| 10 | 1502 不是 Modbus 默认端口 | 要 Decode As，解码器名是 **`mbtcp`** 不是 `modbus` |
| 11 | CODESYS 校验位 EVEN | 真表是 NONE → 每次都超时 |
| 12 | 主从加反 | `Modbus Serial Device` 是从站，要 `Modbus Client, COM Port` |
| 13 | PLC 停机停在最后值 | 勾"自动重启通信"；Application 要手动"启动" |
| 14 | OPC UA 匿名被拒 | 开"允许匿名登录"；None 通道不许明文密码 |
| 15 | 符号配置勾了没下载 | 看不到变量 → 重新编译 + 下载 |
| 16 | 串口独占 | PLC 占了 COM7，Java 就打不开 |
